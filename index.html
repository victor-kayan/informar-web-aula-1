Projeto Informar

Um espaço para aprender, experimentar e criar com tecnologia.

Uma porta de entrada para o mundo digital

Nesta oficina, vamos descobrir como as páginas que usamos todos os dias são construídas.

Começaremos pelo HTML, a linguagem que organiza títulos, textos e imagens dentro de uma página.

Aprender colocando a mão na massa

Durante os encontros, cada conceito será testado diretamente no computador. Poderemos alterar o código, observar o resultado e investigar o que aconteceu.

Nossa primeira missão

Hoje construiremos uma página simples do zero. Depois, cada pessoa poderá criar seu próprio site sobre música, esportes, jogos, filmes, tecnologia ou qualquer outro tema que considere interessante.

Este é apenas o começo

Nas próximas aulas, usaremos CSS para escolher cores, fontes, tamanhos e organizar melhor cada parte da página.
